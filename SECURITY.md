# Security Policy

## Supported versions

This repository publishes a static documentation site. Only the latest
commit on `main` (and the GitHub Pages site built from it) is supported.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/chief-builder/codex_rollout_healthcare/security)
("Report a vulnerability" on the Security tab). Include what you found, where,
and how to reproduce it. You should get an acknowledgement within 7 days.

This repository contains no production systems, credentials, or real patient
data. The plan describes an architecture; it does not deploy one.
